# Security policy

## Scope and supported versions

This repository primarily contains agent skill instructions, metadata, validation scripts, documentation, and CI configuration. Report vulnerabilities that affect these repository contents or their official distribution and validation workflows. Issues in downstream applications or third-party agents are outside this repository's scope unless they are caused by content maintained here.

There is no formal release or security-support policy, and no versions are designated as supported. Security fixes are handled at the maintainers' discretion; no release or backport commitment is implied.

## Reporting a vulnerability

GitHub private vulnerability reporting is enabled for this repository. Submit vulnerability reports privately using [GitHub's Report a vulnerability form](https://github.com/sudeeppatgar/fullstack-skills/security/advisories/new). Do not post sensitive details in public issues, discussions, or pull requests.

Include, where available:

- The affected file, component, or version/commit.
- Reproduction steps and the security impact.
- Relevant logs or a proof of concept, with secrets removed.
- A suggested fix, if you have one.

Do not include credentials, tokens, private data, or other people's personal information.

## Coordinated disclosure and response

Please do not publish vulnerability details or exploit code before coordinating a fix with the maintainers. The project has not established an acknowledgement or follow-up response timeline; maintainers must decide and publish realistic response expectations before making an SLA claim.

Skills should promote defensive, authorized security work and must not direct agents to expose secrets or bypass access controls.

# Third-party skill attribution and licensing

No third-party sources have currently been documented or verified for the seven existing skills. This does not establish whether third-party material is present or whether the skills are original.

If third-party content is introduced, record the following for each affected skill before contributing it:

| Local skill | Source (URL and exact path/version) | Applicable license | Required attribution/notices | Modifications |
|---|---|---|---|---|

Review the source's license and preserve required notices. The repository's MIT license does not determine the terms for third-party content. If permission or terms are unclear, link to the source or ask the rights holder rather than redistributing it.
